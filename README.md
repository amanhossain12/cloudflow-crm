# ☁️ CloudFlow CRM

A modern SaaS CRM landing page built with **React.js**, **Vite**, **Tailwind CSS**, and **Framer Motion**. CloudFlow CRM is designed with a clean, responsive, and SEO-friendly interface to showcase CRM features, pricing, and business solutions.

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/amanhossain12/cloudflow-crm.git
```

Go to the project

```bash
cd cloudflow-crm
```

Install dependencies

```bash
npm install
```

Run locally

```bash
npm run dev
```

Build for production

```bash
npm run build
```
